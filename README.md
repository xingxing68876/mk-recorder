# mk-recorder 鼠标键盘录制回放器

纯本地的鼠标键盘录制回放器:零 AI、零 token、零新增依赖(仅 `pynput` + 标准库 + tkinter),按录制时的真实时间间隔忠实回放。

> 快照型开源,不承诺维护。使用风险见 [DISCLAIMER.md](DISCLAIMER.md)。

## 亮点

- **零 token / 零 AI**:不调用任何大模型或网络接口,全程纯本地运行,无任何数据外传。
- **零新增依赖**:唯一第三方依赖是 `pynput`(pip 一行装完),界面用自带 tkinter。
- **间隔忠实重放**:按录制时的真实时间间隔回放,支持循环 N 次自动停。
- **软停防卡键**:急停在下一事件边界停下,并补发所有未松开的键/按钮,不会把修饰键卡在按下状态。
- **不录鼠标移动轨迹**:只录点击 / 拖拽起止 / 滚轮 / 键盘离散事件,脚本小、回放稳(设计如此)。

## 快速开始

1. 安装依赖(仅一个):

   ```
   pip install pynput
   ```

2. 启动:
   - Windows:双击 `启动.bat`(无黑窗,日志在 `logs/app.log`)。要求 `pythonw` 在 PATH 上(装 Python 时勾选 "Add python to PATH" 即可);找不到的话编辑 `启动.bat` 填自己的 Python 完整路径。
   - 调试:`python main.py`(有控制台,报错直接看)。

## 默认热键

| 键 | 功能 |
|----|------|
| F6 | 录制开关(再按一次停止并保存) |
| F7 | 开始回放 |
| F12 | 急停 |

热键可在界面右侧自定义(小写、`+` 分隔,如 `ctrl+shift+x`),点"保存热键"立即生效。**避开 F10/Alt/Win**(系统语义键)。

## 录制

1. 按 F6(或点 ●录制)开始,状态变 RECORDING
2. 在目标软件里操作——只录 **点击 / 拖拽起止 / 滚轮 / 键盘**,**不录鼠标移动轨迹**
3. 再按 F6(或点 ■停止录制),输入脚本名保存为 `scripts/xxx.json`

## 回放

1. 列表选脚本 → 设循环次数 → 按 F7(或点 ▶回放)
2. 按录制时的真实时间间隔,循环 N 次自动停
3. F12 随时急停(软停:在下一事件边界停,并补发未松开的键,防卡键)

## 已知限制(重要)

- **中文输入不保证复现**:录的是按键,中文靠输入法上屏,回放时输入法状态/候选词不同会变。**对策:含中文的段落改用「复制 + Ctrl+V 粘贴」的方式录制**,粘贴路径 100% 复现。
- **绝对坐标**:换分辨率,或挪动/缩放目标窗口,点击会整体偏。固定位置场景下窗口别动。
- **多显示器**:建议单屏使用,副屏坐标可能有偏差。
- **不支持 DirectInput 游戏 / 管理员权限窗口**:SendInput 可能被忽略(需要 pydirectinput/硬件级注入,后续再说)。
- **不录鼠标移动轨迹**:纯轨迹动画类操作无法复现(设计如此)。
